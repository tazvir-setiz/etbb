# ربات تلگرام ارزیابی فارسی

رباتی فارسی برای ثبت امتیاز افراد در نظرسنجی‌های مستقل و زمان‌دار. همین کد با تنظیم `BOT_PLATFORM` روی تلگرام یا بله اجرا می‌شود. این پروژه با Python 3.11 به بالا، کتابخانه aiogram نسخهٔ ۳، SQLAlchemy ناهمگام و openpyxl ساخته شده است. پایگاه پیش‌فرض SQLite است و با تغییر نشانی اتصال می‌توان از PostgreSQL استفاده کرد.

## قابلیت‌ها

- منوهای فارسی و روند انتخاب نظرسنجی، فرد و امتیاز در تلگرام.
- بازهٔ زمانی جداگانه برای هر نظرسنجی، امتیاز پیش‌فرض ۱ تا ۵، نظر اختیاری، رأی ناشناس و امکان ویرایش رأی.
- جلوگیری از رأی تکراری هم در منطق برنامه و هم با قید یکتایی پایگاه داده.
- پنل جداگانهٔ مدیر با منوی مستقل، مدیریت صفحه‌بندی‌شده و جست‌وجوی افراد، فعال/غیرفعال‌کردن افراد، ساخت مرحله‌ای نظرسنجی، آمار و خروجی Excel.
- مدل‌های ناهمگام و فایل‌های لازم برای اجرای Docker.
- اجرای مشترک روی تلگرام و بله؛ شناسهٔ هر کاربر همراه پلتفرمش نگهداری می‌شود.

## معماری

لایهٔ تلگرام در `app/bot` قرار دارد؛ قواعد رأی‌گیری در `app/services`؛ مدل‌های ذخیره‌سازی در `app/models.py`؛ راه‌اندازی پایگاه در `app/database.py`؛ و ساخت گزارش در `app/exports` است. SQLite برای شروع ساده انتخاب شده و نشانی اتصال async برای PostgreSQL نیز قابل تنظیم است. توضیح بیشتر در [مستند معماری](docs/architecture.md) آمده است.

## پیش‌نیاز و نصب

نسخه‌های Python 3.11 تا 3.14 پشتیبانی می‌شوند. اگر نسخهٔ Python را عوض می‌کنید، محیط مجازی قبلی را کنار بگذارید و محیط تازه بسازید. در پوشهٔ پروژه اجرا کنید:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

در فایل وابستگی‌ها افزونهٔ `asyncio` مربوط به SQLAlchemy فعال شده تا `greenlet` لازم برای اتصال async نیز نصب شود.

فایل `.env` در ریشهٔ پروژه را باز کنید و `BOT_TOKEN` را با توکن ربات در پیام‌رسان انتخابی پر کنید:

| متغیر | نیاز | کاربرد |
|---|---:|---|
| `BOT_TOKEN` | بله | توکن گرفته‌شده از BotFather تلگرام یا پدرِ ربات بله |
| `BOT_PLATFORM` | خیر | `telegram` (پیش‌فرض) یا `bale` |
| `ADMIN_USER_IDS` | برای مدیریت بله | شناسه‌های عددی کاربران در پلتفرم انتخاب‌شده، جداشده با ویرگول |
| `DATABASE_URL` | خیر | پیش‌فرض پایگاه SQLite محلی؛ برای PostgreSQL از `postgresql+psycopg://user:pass@host/db` استفاده کنید |
| `TIMEZONE` | خیر | منطقهٔ زمانی مستندات، پیش‌فرض `Asia/Tehran` |
| `LOG_LEVEL` | خیر | سطح ثبت گزارش، پیش‌فرض `INFO` |

در [BotFather تلگرام](https://t.me/BotFather) یا «پدرِ ربات» بله در [ble.ir/botfather](https://ble.ir/botfather) ربات بسازید. `BOT_PLATFORM` را روی `telegram` یا `bale` بگذارید و توکن همان ربات را در `BOT_TOKEN` قرار دهید. شناسهٔ عددی مدیر باید متعلق به همان پیام‌رسان انتخاب‌شده باشد و در `ADMIN_USER_IDS` بیاید. فایل `.env` نباید وارد Git شود.

API بله با Bot API تلگرام سازگاری زیادی دارد؛ در حالت بله، برنامه به `https://tapi.bale.ai` وصل می‌شود و همان منطق و روند رأی‌گیری را به کار می‌گیرد. برای تغییر پلتفرم، برنامه را با توکن و تنظیم مربوط اجرا کنید. هر دو پلتفرم می‌توانند از یک پایگاه داده استفاده کنند؛ شناسهٔ کاربر به همراه نام پلتفرم ذخیره می‌شود.

## اجرا

```powershell
python -m app.main
```

جدول‌ها هنگام اجرا ساخته می‌شوند و ستون شناسهٔ کاربران نسخهٔ قبلی نیز خودکار به ساختار پلتفرم‌دار مهاجرت می‌کند. پیش از ارتقای پایگاه دارای اطلاعات نسخهٔ پشتیبان بگیرید؛ فعلاً ابزار عمومی مدیریت نسخه‌های پایگاه داده وجود ندارد.

## فرمان‌های مدیر

شناسه‌های مدیر را در `ADMIN_USER_IDS` قرار دهید. مدیر با `/start` مستقیماً پنل مدیریت را می‌بیند و می‌تواند با «🎭 حالت ارزیاب» به منوی رأی‌دهی برود. فهرست افراد امکان صفحه‌بندی، جست‌وجو و فعال/غیرفعال‌کردن دارد؛ برای افزودن فرد و ساخت نظرسنجی، فرم‌های مرحله‌ای در پنل قرار دارند. همهٔ دکمه‌ها و پیام‌های مدیریتی دوباره مجوز مدیر را بررسی می‌کنند.

```text
/addperson P-001|علی|رضایی
/addsurvey ارزیابی مهر|2026-10-08T09:00:00+03:30|2026-10-09T17:00:00+03:30|1,2
/reports
/export 1
```

تاریخ‌ها باید ISO-8601 باشند؛ زمان بدون منطقهٔ زمانی، به‌وقت `TIMEZONE` تفسیر می‌شود. شناسهٔ افراد در فرمان قدیمی همان شناسهٔ رکورد در پایگاه داده است. فردی که در نظرسنجی قبلی استفاده شده حذف نمی‌شود؛ در عوض می‌توان آن را غیرفعال کرد تا در رأی‌گیری‌های تازه ظاهر نشود. ویرایش مشخصات فرد، ویرایش یا لغو نظرسنجی، تنظیمات و مدیریت نقش مدیران هنوز پیاده‌سازی نشده‌اند. وضعیت فرم‌های در حال انجام فعلاً در حافظه است و با راه‌اندازی مجدد ربات از بین می‌رود.

## Docker

ابتدا `.env` را بسازید و سپس اجرا کنید:

```powershell
docker compose up --build -d
```

فایل Compose پوشهٔ `./data` را متصل می‌کند. نشانی پیش‌فرض SQLite در پوشهٔ کاری کانتینر نوشته می‌شود؛ برای ماندگاری داده در پوشهٔ متصل‌شده، `DATABASE_URL=sqlite+aiosqlite:////data/survey_bot.db` را در `.env` قرار دهید. برای چند نمونهٔ هم‌زمان، PostgreSQL مناسب‌تر است.

## گزارش Excel

مدیر فرمان `/export <شناسه نظرسنجی>` را می‌فرستد. فایل XLSX شامل برگهٔ خلاصه و برگهٔ امتیازهاست. در نظرسنجی ناشناس، نام و شناسهٔ تلگرام رأی‌دهنده در فایل درج نمی‌شود. فایل‌ها را با دسترسی محدود نگه دارید.

## پشتیبان‌گیری و بازیابی

برای SQLite ربات را متوقف کنید و از فایل پایگاه داده نسخهٔ پشتیبان بگیرید. هنگام بازیابی نیز ربات باید متوقف باشد. برای PostgreSQL از `pg_dump` و `pg_restore` استفاده کنید. نسخه‌های پشتیبان را رمزگذاری و دسترسی به آن‌ها را محدود کنید. ساختار کلید کاربر در نسخهٔ جدید تغییر کرده است؛ اگر پایگاه نسخهٔ قبلی را دارید، پیش از ارتقا نسخهٔ پشتیبان بگیرید؛ برنامه در شروع ستون و قید یکتایی کاربران را خودکار ارتقا می‌دهد.

## امنیت و محدودیت‌ها

رازها از متغیر محیطی خوانده می‌شوند و فایل محیطی، پایگاه داده، گزارش‌ها و فایل‌های موقت در Git نادیده گرفته شده‌اند. یکتایی رأی در پایگاه نیز اعمال می‌شود. فرمان‌های مدیر و دکمهٔ گزارش دوباره مجوز را بررسی می‌کنند. شناسهٔ داخلی کاربر برای جلوگیری از رأی تکراری نگهداری می‌شود، اما شناسهٔ رأی‌دهنده در خروجی نظرسنجی ناشناس حذف می‌شود. دسترسی فایل‌ها و اتصال PostgreSQL را در میزبان به‌درستی محدود کنید. این نسخه هستهٔ رأی‌گیری و گزارش را فراهم می‌کند و همهٔ چرخه‌های مدیریتی درخواستی را پوشش نمی‌دهد؛ موارد باقی‌مانده در بالا مشخص شده‌اند.

## رفع اشکال

- پیام نیاز به `BOT_TOKEN`: فایل `.env.example` را به `.env` کپی و توکن را تنظیم کنید.
- ربات پاسخ نمی‌دهد: توکن، دسترسی اینترنت و اجرای هم‌زمان نمونهٔ دیگر ربات را بررسی کنید.
- منوی مدیریت دیده نمی‌شود: شناسهٔ عددی را در `ADMIN_USER_IDS` بررسی و `/start` را دوباره ارسال کنید.
- خطای نوشتن SQLite: دسترسی نوشتن پوشه و استفادهٔ هم‌زمان چند پردازه از فایل SQLite را بررسی کنید.
